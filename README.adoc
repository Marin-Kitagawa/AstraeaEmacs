✦ *Astraea Emacs* ✦ — _the most feature-rich, most performant Emacs framework._

Astraea fuses the best of three worlds:

[cols="1,3"]
|===
| source | what it contributes

| *Spacemacs*
| layer system, `SPC`-leader keymaps, transient discoverable menus, which-key

| *scimax*
| scientific org stack: jupyter notebooks, citar citations, CDLaTeX/AUCTeX, org-roam, pandoc publishing

| *AstroNvim*
| polished dashboard/modeline/tree UI, LSP + formatter + debugger toolchain, lazy-first performance
|===

…plus a *runtime-switchable modal engine* (zetta-style): evil and meow are both
installed, share one keymap, and can be swapped with a single command.

== 1. Install

[cols="1,2"]
|===
| Requirement | Notes

| *Emacs 30+*
| 31 recommended — ships built-in treesit, eglot, editorconfig

| Git
| elpaca clones via git; also used for the framework bootstrap

| A Nerd Font

=== 1.1 Standard install

[source,powershell]
----
git clone https://github.com/astraea-emacs/astraea ~/projects/astraea-emacs
runemacs.exe   # or: emacs --init-directory ~/projects/astraea-emacs
----

The first launch installs all packages in parallel through **elpaca** (async
package manager with native-comp integration). Your configuration is seeded to
`~/.astraea.d/init.el` — the framework directory stays pristine, so framework
upgrades never clobber your personal setup.

=== 1.2 Windows: make `runemacs.exe` pick up Astraea automatically

Create an NTFS *directory junction* (no admin or Developer Mode required):

[source,powershell]
----
Rename-Item C:\Users\Ahri\.emacs.d .emacs.d.pre-astraea   # if it exists
New-Item -ItemType Junction -Path C:\Users\Ahri\.emacs.d `
         -Target C:\Users\Ahri\projects\astraea-emacs
----

After this, plain `runemacs.exe` loads Astraea natively. A real symlink also
works if you have Developer Mode enabled.

=== 1.3 Updating

Run `M-x elpaca-update-all`, or restart — failed orders are retried
automatically. Inspect anything with `M-x elpaca-manager`.

"""

== 2. Performance philosophy

Astraea treats startup time and idle memory as first-class features:

* `early-init.el` defers garbage collection, strips file-name handlers, and
  removes frame chrome before the GUI exists.
* **Every** package defers until first use (`:commands`, `:hook`, `:after`).
* elpaca installs and AOT-native-compiles packages **in parallel**
  (`elpaca-queue-limit 4` on Windows to keep `git.exe` stable).
* `gcmh` throttles GC at idle; extra collection runs on frame focus loss.
* All state lives outside `user-emacs-directory` via `no-littering`.
* `M-x astraea/report-startup-time` and `M-x astraea/profile-startup`
  give measurable feedback.

"""

== 3. Architecture

The startup pipeline is linear and fully traceable; every stage is a single
inspectable function.

Warm starts (everything already built) run `astraea//finish-init`
synchronously inside `astraea/init`; cold first installs defer it to elpaca's
post-queue hooks and an idle-timer fallback.

== 4. Modal editing (zetta-style switching)

Both engines are installed together; your muscle memory never breaks because
**the same `SPC` leader map works under both**.

[source]
----
M-x astraea/set-modal-style RET meow RET   ; live switch, no restart
M-x astraea/toggle-modal-style             ; or SPC t m
----

[cols="1,2,2"]
|===
| style | engine | best for

| `evil`
| full Vim emulation (evil-collection everywhere)
| spacemacs/Vim muscle memory

| `meow`
| modern native modal, keypad + selection-first
| Emacs-native feel with modal editing

| `hybrid`
| evil with native Emacs insert-state bindings
| Vim motions + Emacs muscle memory in insert
|===

Defaults: `jk` fast-escape (better-escape), `gcc`/`gc` commenting
(evil-commentary), surround operators, `g C-a` number increment.

== 10. Layers

image::layers.svg[Layer system]

A layer is a named bundle of packages + init/config hooks + keybinds, declared
with `astraea-layer!` and enabled with `astraea/enable-layer`.

=== 10.1 Authoring a file layer

Create `layers/astraea-layer-+category-name.el`:

[source,elisp]
----
(astraea-layer! +lang/rust
  :packages (rustic)
  :init  (elpaca rustic)                       ; queue installation
  :config (setq rustic-format-on-save t)       ; run after activation
  :keybinds (astraea/leader-def "m r" #'rustic-cargo-run))

(provide 'astraea-layer-rust)
----

Enable it from user config: `(astraea/enable-layer '+lang/rust)`.

[cols="1,2"]
|===
| hook | when it runs

| `:init`
| during `astraea/init`, before elpaca processes queues

| `:config`
| once packages are activated (warm start: synchronously; cold start: after the queue drains)

| `:keybinds`
| after `:config`, once the leader map exists
|===

Inspect the live registry with `SPC h L` (`M-x astraea/list-layers`).

== 13. Troubleshooting

[cols="1,2"]
|===
| symptom | fix

| "Org version mismatch" warning
| benign — newer Org is installed via elpaca; loads correctly after startup

| `git.exe` access-violation dialogs during install
| Astraea caps elpaca parallelism at 4 on Windows; also update Git for Windows

| "Unable to find main elisp file" for package X
| stale/partial clone of X — delete `elpaca/sources/X/` and restart

| symlink errors on Windows
| already handled: `elpaca-no-symlink-mode` is enabled on `windows-nt`

| emacsclient refuses to connect
| stale auth file is auto-deleted at startup; or `M-x server-force-delete` + `M-x server-start`

| a package order shows "failed"
| `M-x elpaca-manager`, mark for retry; or just restart — failures re-queue automatically
|===

== 14. FAQ

* *Does it have a dashboard?* — Yes, spacemacs-style with an image banner
  (`astraea-dashboard-banner`), icon sections and a friendly footer.
* *Can I switch evil ⇄ meow without restarting?* — Yes:
  `M-x astraea/set-modal-style` or `SPC t m`.
* *Will an upgrade wipe my config?* — No. User config lives in
  `~/.astraea.d/`; the framework directory is disposable/re-cloneable.
* *Windows support?* — First-class: UTF-8 pwsh shell, no-symlink installs,
  capped parallel git, junction-based auto-loading.

== 15. Design decisions

1. **One leader map, two engines** — `astraea-leader-map` is a plain keymap
   bound to `SPC` in evil's states and meow's normal state alike.
2. **Layers are data, not includes** — a layer is a plist on a symbol;
   enable order is independent of load order, and inline layers live in
